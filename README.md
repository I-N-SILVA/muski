# Muski

Muski is a private listening instrument for macOS and Windows. The public repository is the official home for the browser preview, signed desktop releases, checksums, privacy information, and support.

## Try the browser player

Open the [Muski web preview](https://i-n-silva.github.io/muski/). It can play audio selected from your phone or computer without uploading it. The generated Muski loop provides an instant copyright-safe demonstration.

On a supported mobile browser, use **Add to Home Screen** to install the preview as a lightweight PWA. The interface shell works offline after the first visit; selected audio remains temporary and device-local.

The browser preview intentionally has no downloader, account, analytics, server, or permanent library access. Browsers may forget selected files when the tab closes.

## Desktop edition

The desktop edition adds a persistent local vault, metadata editing, artwork, lyrics, favorites, folders, tags, mixtapes, queue persistence, A/B looping, and reactive visualizers. Signed installers will appear under [Releases](https://github.com/I-N-SILVA/muski/releases) after platform signing and clean-machine QA are complete.

Public builds are store-safe and do not contain yt-dlp, remote acquisition commands, or translation sidecars.

## Trust and support

- Verify the checksum published with every installer.
- Download only from this repository's Releases page.
- Read [PRIVACY.md](PRIVACY.md) before using the preview or desktop app.
- Use [SUPPORT.md](SUPPORT.md) for help and private security-reporting instructions.
